#  ROOMEASE  
##  Full-Stack Hotel Booking Web Application  

---

##  Overview  

**RoomEase** is a full-stack hotel booking web application built using the **MERN stack (MongoDB, Express.js, React.js, Node.js)**.

The platform allows users to:

-  Browse available rooms  
-  Check real-time availability  
-  Make and manage reservations  

RoomEase simulates a **real-world hotel booking system** with dynamic data handling, protected routes, and scalable backend architecture.
